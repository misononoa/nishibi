# nishibi-bbs

`bbs.misononoa.cc`用のシンプルなシングルスレッド掲示板Webアプリケーションです。

## 構成

- PostgreSQL 18
- Spring Data JPA + JPA Hibernate
- Spring Web MVC
  - Thymeleaf
